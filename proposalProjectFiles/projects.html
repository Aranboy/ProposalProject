Project 3: Rest Api Automation framework

I worked on an automated REST API integration test suite for the Document Management Service, a platform that handles uploading, searching, transferring, and managing the lifecycle of documents across the company's divisions. The suite is built in Java 17 with JUnit 5 and REST-assured and runs against real deployed environments (local, dev, stage, and feature branches) instead of mocks. It authenticates through Okta, runs tests in parallel, and cleans up all the data it creates. It's organized into clear layers (tests, reusable step classes, test-data enums, and a custom assertion library), and it runs automatically in GitHub Actions CI on every push to dev and feature branches. The work shows I can design maintainable test frameworks, build for concurrency and reliability, and work with enterprise tooling like Maven, OAuth, and CI/CD pipelines.
